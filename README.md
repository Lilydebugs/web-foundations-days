# QuickNotes

QuickNotes is a simple web application for creating, managing, searching, and deleting notes.

## Features

- Add notes with a category
- Categories: Personal, Work, and Study
- Validate empty notes and notes longer than 200 characters
- Delete individual notes
- Display the number of saved notes
- Search notes as you type
- Save notes using localStorage so they remain after refreshing the page
- Responsive layout for smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript
- localStorage

## How to Use

1. Type a note in the input field.
2. Select a category.
3. Click **Add Note**.
4. Use the search box to find notes.
5. Click **Delete** to remove a note.

## Project Structure

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — note functionality, validation, search, and localStorage
